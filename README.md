# 烟幕干扰弹的投放策略 —— 2025 高教社杯全国大学生数学建模竞赛 A 题

> 省级二等奖 ｜ 第一负责人 ｜ MATLAB + Python + SciPy

无人机投放烟幕弹遮蔽真目标，使来袭导弹无法看清目标。要求在给定约束下优化烟幕弹的
**投放速度 / 航向 / 投放时刻 / 起爆延迟**，使**有效遮蔽时间**最长。

本仓库是参赛时的完整求解代码与结果。

---

## 一、核心思路

### 1. 把「视线有没有被挡住」写成几何判据

把导弹视作点光源，烟幕球在其后方形成一个**圆锥形视野盲区**：以导弹为顶点、向烟幕球
作**切锥**。若真目标落在该锥体内，则视线被遮蔽。

由于真目标是一个圆柱体，判定时在其**上下底面两个平面**上分别判定覆盖关系，取交集。

### 2. 把不可导的布尔判定变成可优化的连续目标

「在锥内 / 不在锥内」是一个阶跃函数，无法求导。为此定义：

- `α` —— 切锥半顶角（由导弹与烟幕球的几何关系随时间变化）
- `β` —— 视线方向与锥轴方向的夹角

构造平滑的**遮蔽质量函数** `Q(t) ∈ [0, 1]`：

```
β ≤ α            →  Q(t) ≈ 1                （完全遮蔽）
β > α            →  Q(t) 按三次方快速衰减到 0  （锥外）
```

再对 `Q(t)` 在 `[起爆时刻, 起爆时刻 + 20s]` 上积分作为目标函数——**积分值越大，遮蔽越充分**。
`Q` 可微，于是可以用梯度法与全局进化算法求解。

### 3. 求解策略

| 问题 | 策略 |
|---|---|
| 一 | 固定策略，解析几何直接计算遮蔽起止时刻 |
| 二 / 三 | 网格搜索提供初值 + 梯度下降（局部精化） |
| 四 / 五 | **差分进化（Differential Evolution）** 全局搜索 + L-BFGS-B 局部精化，`numba` 加速目标函数 |

关键常量：`g = 9.80665 m/s²`、导弹速度 `300 m/s`、烟幕下沉 `3 m/s`、烟幕半径 `10 m`、
无人机速度约束 `70~140 m/s`、相邻投放间隔 `≥ 1 s`。

---

## 二、结果

| 问题 | 场景 | 最大有效遮蔽时长 |
|---|---|---|
| 一 | 给定固定投放策略 | **1.4244 s** |
| 二 | 单机单弹，优化速度 / 航向 / 投放时刻 / 起爆延迟 | **≈4.08 s**（v = 133.64 m/s，航向 7.41°） |
| 三 | 单机投放 3 枚烟幕弹 | **6.2503 s** |
| 四 | 3 架无人机各投 1 枚 | **12.336 s**（三机分别贡献 3.07 / 6.40 / 3.96 s） |
| 五 | 5 架无人机，每架最多 3 枚，干扰 3 枚导弹 | **23.63 s** |

结果均用解析几何做了交叉验证，逐枚弹的策略与时长见 `results/result*.xlsx`。
